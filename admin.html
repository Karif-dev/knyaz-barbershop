GitHub и деплой
Публикация на сайте работает через Railway автодеплой из GitHub.

Необходимые переменные в Railway:
GITHUB_TOKEN — токен с доступом к репо
GITHUB_REPO — Karif-dev/knyaz-barbershop
GITHUB_BRANCH — main
SECRET_KEY — любая случайная строка

После сохранения изменений Railway перезапускается (~2 мин) и обновления появляются на сайте.
